# HellClicker for Windows — WEAK EDITION

**Слабый порт** кликера Хэллоуин в аду на настоящий Windows.

- Чистый WinAPI + GDI, без DirectX, без движка, без мозгов.
- Окно 640x480, один буфер, один шрифт, одна мышь.
- Офисный белый фон. Как в старых Windows.
- Сборка: `zig cc -target x86_64-windows-gnu -O2 -lgdi32 -luser32 -Wl,--subsystem,windows -o HellClicker.exe clicker.c`

## Как играть

1. Скачай `HellClicker.exe`.
2. Запусти. Windows 10 просто умрёт от слабости, но игра работает.
3. Кликай по экрану: `SLAY! x%d`.
4. Клавиша `A` — включить/выключить автотап (`AUTO: ON (x0.5)`).
5. Клавиша `R` — сброс счёта.

## Механики (v0.0.1, максимально слабые)

- Тап = +1.0 к счёту (с дробями, потому что это слабость).
- Автотап = +0,5 каждые 200 мс.
