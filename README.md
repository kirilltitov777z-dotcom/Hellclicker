# Hellclicker

**Hellclicker** — idle-кликер о пасти и аду. Ты — последний герой, спускающийся в Ад за золотом и славой.

## Идея

Гибрид кликера и казуалки: автобой + ручные тапы.

- Герой автоматически бьёт ближайшего демона.
- Ты можешь тапать по демону — быстрая атака.
- Убийства дают опыт и золото.
- Герой растёт: уровень → урон, HP, награды.
- Максимальный уровень → **Восстание** → души → вечный урон.
- Магазин улучшений: молот, призвание скелета, кладовка.
- Достижения.
- **Хэллоуин в Аду**: двойной опыт и золото в сезон Хэллоуина.

## Как играть

Открой `web/index.html` в браузере на телефоне (или запусти локальный сервер):

```bash
cd holoclicker/web
python3 -m http.server 8080
# потом открыть http://localhost:8080
```

Или просто открой файл `web/index.html` — игра в PWA (manifest + service worker), ставится на телефон как приложение.

## Структура

- `web/index.html` — игровой экран
- `web/style.css` — стили (тёмная адская тема, мобильный UI)
- `web/game.js` — логика игры
- `web/manifest.json` + `web/service-worker.js` — PWA
- `web/icon-*.png`, `web/manrobe-*.woff2` — ассеты
- `assets/android/` — иконки для будущего Android APK (Capacitor)
- `.github/workflows/` — CI

## Мехники

1. **Бой**: автобой каждые ~0.8с, тап — мгновенная атака, критический урон x2.
2. **Герой**: уровень 1–25, опыт от убийств, HP = 60 + 8*уровень.
3. **Магазин**: 3 улучшения (0–5 уровень), денежные траты.
4. **Восстание**: при 25 уровне герой может «восстать» — получает души, сила растёт на 10% за душу.
5. **Хэллоуин**: 20.10–05.11 — x2 опыт и золото, спецдемон 🎃.
